# sdk-api (retired)

> **This project is retired and archived.** Development continues in **Orion**:
> github.com/natuleadan/orion

`sdk-api` was Natuleadan's the Go SDK for scaffolding, running and scaling event-driven backends. It has been superseded by Orion, a new project that carries its work forward. Please follow the Orion repository for documentation, releases and support.

## For Go users

- Every earlier version of `github.com/natuleadan/sdk-api` is retracted, so `go get` and `go list -m -u` will warn you.
- This module is marked deprecated; no further versions will be published.
- There is no drop-in upgrade path. Start from the Orion repository.
